1. ผู้ควบคุมข้อมูลส่วนบุคคล

BOTIFY เป็นผู้ควบคุมข้อมูลส่วนบุคคล (Data Controller) สำหรับข้อมูลของผู้ใช้บริการ (เจ้าของร้านค้า) และเป็นผู้ประมวลผลข้อมูล (Data Processor) สำหรับข้อมูลของลูกค้าปลายทางที่สนทนากับแชทบอทของร้านค้า

2. ข้อมูลส่วนบุคคลที่เก็บรวบรวม

ข้อมูลนัดหมายชื่อ, เบอร์โทร, บริการ, วันเวลานัด

3. วัตถุประสงค์และฐานทางกฎหมาย

วัตถุประสงค์ฐานทางกฎหมาย (PDPA)
ให้บริการแชทบอทและแดชบอร์ดการปฏิบัติตามสัญญา (ม.24(3))
จัดการออเดอร์และนัดหมายการปฏิบัติตามสัญญา (ม.24(3))
แจ้งเตือนออเดอร์ใหม่/แชทใหม่ผ่าน LINEประโยชน์โดยชอบด้วยกฎหมาย (ม.24(5))
ปรับปรุงและพัฒนาบริการประโยชน์โดยชอบด้วยกฎหมาย (ม.24(5))
เรียกเก็บค่าบริการการปฏิบัติตามสัญญา (ม.24(3))
ป้องกันการฉ้อฉลและรักษาความปลอดภัยประโยชน์โดยชอบด้วยกฎหมาย (ม.24(5))
ส่งข่าวสารการตลาดความยินยอม (ม.19)
ปฏิบัติตามกฎหมายหน้าที่ตามกฎหมาย (ม.24(6))

4. การเปิดเผยข้อมูลแก่บุคคลที่สาม

BOTIFY อาจเปิดเผยข้อมูลส่วนบุคคลแก่บุคคลที่สามดังต่อไปนี้:

ผู้รับข้อมูลวัตถุประสงค์
Supabase (Auth & Database)จัดเก็บข้อมูลบัญชีผู้ใช้และข้อมูลร้านค้า
LINE Corporationรับ-ส่งข้อความผ่าน LINE Messaging API
Meta Platforms (Facebook)รับ-ส่งข้อความผ่าน Messenger Platform
Google (Sheets API)เก็บข้อมูลสินค้า ออเดอร์ ในรูปแบบ spreadsheet
Anthropic / OpenAI / Google AIประมวลผลภาษาธรรมชาติสำหรับแชทบอท
หน่วยงานราชการเมื่อได้รับคำสั่งตามกฎหมาย

BOTIFY จะไม่ขายข้อมูลส่วนบุคคลของท่านให้แก่บุคคลที่สามเพื่อวัตถุประสงค์ทางการตลาด

5. การส่งข้อมูลไปต่างประเทศ

ข้อมูลของท่านอาจถูกส่งไปยังเซิร์ฟเวอร์ในต่างประเทศ ผ่านผู้ให้บริการดังนี้:

  • Supabase — เซิร์ฟเวอร์ในสิงคโปร์หรือสหรัฐอเมริกา
  • Anthropic / OpenAI — สหรัฐอเมริกา (สำหรับประมวลผล AI)
  • Google Cloud — เซิร์ฟเวอร์หลายภูมิภาค

ผู้ให้บริการเหล่านี้มีมาตรการคุ้มครองข้อมูลที่เพียงพอตามมาตรฐานสากล (เช่น SOC 2, ISO 27001) ตามที่ PDPA มาตรา 28 กำหนด

ประเภทข้อมูลระยะเวลาเก็บรักษา
ข้อมูลบัญชีผู้ใช้ตลอดระยะเวลาที่ใช้บริการ + 30 วัน หลังยกเลิก
ประวัติแชท (chat_logs)90 วัน นับจากวันที่สนทนา

ข้อมูลลูกค้าปลายทางเท่ากับระยะเวลาบัญชีของเจ้าของร้าน + 30 วัน

7. สิทธิของเจ้าของข้อมูล

ภายใต้ PDPA ท่านมีสิทธิดังต่อไปนี้ โดยสามารถใช้สิทธิได้ผ่านช่องทางติดต่อในข้อ 13
  • สิทธิในการเข้าถึง (ม.30) — ขอสำเนาข้อมูลส่วนบุคคลของท่านที่เราเก็บรวบรวม
  • สิทธิในการแก้ไข (ม.35) — ขอแก้ไขข้อมูลที่ไม่ถูกต้องหรือไม่สมบูรณ์
  • สิทธิในการลบ (ม.33(5)) — ขอลบข้อมูลเมื่อหมดความจำเป็น หรือถอนความยินยอม
  • สิทธิในการระงับการใช้ (ม.34) — ขอระงับการใช้ข้อมูลชั่วคราว
  • สิทธิในการโอนย้ายข้อมูล (ม.31) — ขอรับข้อมูลในรูปแบบที่อ่านได้ด้วยเครื่อง
  • สิทธิในการคัดค้าน (ม.32) — คัดค้านการเก็บรวบรวม ใช้ หรือเปิดเผยข้อมูล
  • สิทธิในการถอนความยินยอม (ม.19 วรรคห้า) — ถอนความยินยอมได้ทุกเมื่อ โดยไม่กระทบต่อการประมวลผลที่เกิดขึ้นก่อนหน้า
  • สิทธิในการร้องเรียน (ม.73) — ร้องเรียนต่อคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล

BOTIFY จะดำเนินการตามคำร้องภายใน 30 วัน นับจากวันที่ได้รับคำร้องพร้อมเอกสารยืนยันตัวตน

8. การรักษาความปลอดภัยของข้อมูล

BOTIFY ใช้มาตรการรักษาความปลอดภัยดังต่อไปนี้:

  • การเข้ารหัส — ข้อมูลระหว่างการส่งเข้ารหัสด้วย TLS 1.2+ และรหัสผ่านเข้ารหัสด้วย bcrypt
  • การควบคุมการเข้าถึง — Row Level Security (RLS) ใน Supabase ป้องกันการเข้าถึงข้ามร้าน
  • Rate Limiting — จำกัดจำนวนคำร้องเพื่อป้องกัน brute-force
  • Security Headers — Helmet.js สำหรับป้องกัน XSS, clickjacking และการโจมตีทั่วไป
  • Input Validation — ตรวจสอบและทำความสะอาดข้อมูลนำเข้าทุกจุด
  • Token Management — Access Token มีอายุจำกัด, Refresh Token สำหรับต่ออายุ

9. คุกกี้และเทคโนโลยีติดตาม

BOTIFY ใช้เทคโนโลยีต่อไปนี้:

ประเภทวัตถุประสงค์ระยะเวลา
Session Storageเก็บ Token สำหรับล็อกอินตลอดเซสชัน (ปิดแท็บ = ลบ)
Session Cookieจดจำสถานะล็อกอินตลอดเซสชัน

BOTIFY ไม่ใช้คุกกี้ติดตามเพื่อโฆษณา (Advertising Cookies) และไม่ใช้ Analytics ภายนอก เช่น Google Analytics ในปัจจุบัน

10. ข้อมูลของลูกค้าปลายทาง

สำหรับเจ้าของร้าน: ท่านเป็น "ผู้ควบคุมข้อมูลร่วม" สำหรับข้อมูลลูกค้าปลายทาง ท่านมีหน้าที่แจ้งลูกค้าของท่านเกี่ยวกับการใช้แชทบอท AI และการเก็บข้อมูล ตาม PDPA

BOTIFY ในฐานะผู้ประมวลผลข้อมูล จะ:

  • ประมวลผลข้อมูลลูกค้าปลายทางเฉพาะตามคำสั่งของเจ้าของร้าน
  • ไม่ใช้ข้อมูลลูกค้าปลายทางเพื่อวัตถุประสงค์อื่นใดนอกเหนือจากการให้บริการ
  • ลบข้อมูลลูกค้าปลายทางเมื่อเจ้าของร้านยกเลิกบริการ
  • ช่วยเหลือเจ้าของร้านในการตอบสนองต่อคำร้องขอใช้สิทธิ์ของลูกค้าปลายทาง

11. ข้อมูลผู้เยาว์

บริการ BOTIFY มีไว้สำหรับผู้ที่มีอายุ 18 ปีขึ้นไป เราจะไม่จงใจเก็บรวบรวมข้อมูลจากบุคคลที่มีอายุต่ำกว่า 18 ปี หากพบว่าได้เก็บรวบรวมข้อมูลดังกล่าว เราจะดำเนินการลบทันที

12. การแก้ไขนโยบาย

BOTIFY อาจแก้ไขนโยบายนี้เป็นครั้งคราว โดยจะแจ้งให้ทราบผ่าน:

  • อีเมลที่ลงทะเบียนไว้
  • ประกาศบนแดชบอร์ด
  • ป้ายแจ้งเตือนเมื่อเข้าสู่ระบบ

การแก้ไขจะมีผลบังคับใช้หลังจากแจ้งล่วงหน้า 14 วัน เว้นแต่กฎหมายกำหนดให้มีผลทันที
