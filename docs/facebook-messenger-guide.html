คู่มือการตั้งค่า Facebook Messenger API

วิธีสร้าง Page Access Token & Page ID สำหรับเชื่อมต่อกับ Botify

Botify Docs v1.0
คู่มือนี้จะอธิบายขั้นตอนการสร้าง Page Access Token และการหา Page ID จาก Meta for Developers เพื่อนำไปกรอกในระบบ Botify สำหรับเชื่อมต่อบอทเข้ากับเพจ Facebook ของคุณ
1
สร้างแอปใน Meta for Developers
  • เปิดเบราว์เซอร์แล้วไปที่ developers.facebook.com จากนั้นล็อกอินด้วยบัญชี Facebook ของคุณ
  • คลิกที่เมนู "My Apps" (แอปของฉัน) ที่มุมขวาบนของหน้าเว็บ
  • คลิกปุ่ม "Create App" (สร้างแอป) สีฟ้าด้านขวาบน
  • เมื่อมีป๊อปอัปถามประเภทแอป ให้เลือก "Other" → "Business" แล้วกด Next
  • กรอก App Name ตั้งชื่อให้จดจำได้ง่าย เช่น Botify MyShop และกรอกอีเมลสำหรับติดต่อ
  • คลิก "Create App" และยืนยันด้วยรหัสผ่าน Facebook หากมีป๊อปอัปถาม
2
เพิ่ม Messenger API เข้าไปในแอป
  • หลังสร้างแอปสำเร็จ ระบบจะพาไปที่หน้า App Dashboard โดยอัตโนมัติ
  • เลื่อนหน้าลงมาจนเจอการ์ดที่ชื่อว่า "Messenger"
  • คลิกปุ่ม "Set Up" (ตั้งค่า) ในการ์ด Messenger
  • ระบบจะพาคุณไปที่หน้า Messenger API Settings โดยอัตโนมัติ
3
สร้าง Page Access Token และหา Page ID
  • ในหน้า Messenger Settings ให้เลื่อนลงมาที่หัวข้อ "Access Tokens"
  • คลิกปุ่ม "Add or Remove Pages"
  • ป๊อปอัป Facebook จะเด้งขึ้นมา ให้เลือกเพจที่ต้องการเชื่อมต่อกับบอท แล้วกดยืนยันและอนุมัติสิทธิ์ทั้งหมด
  • เมื่อผูกเพจสำเร็จ ชื่อเพจของคุณจะปรากฏในตาราง พร้อมกับ Page ID ที่อยู่ใต้ชื่อเพจ — คัดลอกตัวเลขนี้ไว้
  • คลิกปุ่ม "Generate Token" ที่อยู่ในแถวของเพจนั้น
  • ป๊อปอัปจะแสดง Token ยาวๆ ออกมา ให้กดยืนยันแล้ว คัดลอกทันที ก่อนกดปิด
⚠️
สำคัญมาก! Page Access Token จะแสดงให้เห็นเพียงครั้งเดียวเท่านั้น หากปิดป๊อปอัปโดยไม่คัดลอก จะต้องกด Generate Token ใหม่อีกครั้ง

4
กรอกข้อมูลในระบบ Botify
  • เปิดระบบ Botify แล้วไปที่เมนู "ช่องทางเชื่อมต่อ" (Channels)
  • คลิกที่แท็บ "Facebook Messenger"
  • วาง Page Access Token ที่คัดลอกมาลงในช่อง Page Access Token
  • วาง Page ID ลงในช่อง Page ID
  • คลิกปุ่ม "บันทึก" เพื่อบันทึกการตั้งค่า
💡
หลังบันทึกแล้ว ระบบจะเชื่อมต่อกับ Facebook Webhook โดยอัตโนมัติ คุณสามารถทดสอบโดยส่งข้อความมาที่เพจได้เลย
5
เปิดใช้งานแอปสำหรับสาธารณะ (App Review)
  • ในโหมด Development บอทจะตอบได้เฉพาะบัญชีที่เป็น Admin, Developer, หรือ Tester ของแอปเท่านั้น
  • เพื่อให้บอทตอบกลับลูกค้าทั่วไปได้ ต้องขอ App Review จาก Meta
  • ไปที่เมนูด้านซ้าย → App Review → Requests
  • ร้องขอสิทธิ์ pages_messaging และส่งเอกสารประกอบตามที่ Meta กำหนด
  • เมื่อได้รับอนุมัติ ให้เปลี่ยน App Mode จาก Development เป็น Live
ℹ️
ขั้นตอน App Review อาจใช้เวลา 1–7 วันทำการ สำหรับการทดสอบเบื้องต้นสามารถเพิ่มบัญชีทดสอบเป็น Tester ในหน้า Roles ได้ก่อน
📋
สรุปข้อมูลที่ต้องเตรียม
ข้อมูลที่ต้องใช้ วิธีหา นำไปใส่ในช่อง
Page Access Token Messenger Settings → Access Tokens → Generate Token Page Access Token ใน Botify
Page ID ตัวเลขข้างใต้ชื่อเพจในตาราง Access Tokens Page ID ใน Botify
