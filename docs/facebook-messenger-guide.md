# คู่มือการตั้งค่า Facebook Messenger API (Page Access Token & Page ID)

การตั้งค่าเพื่อนำ **Page Access Token** และ **Page ID** มาใส่ในระบบ Botify มีขั้นตอนง่าย ๆ ดังนี้ครับ

## 1. การสร้าง App ใน Meta for Developers

1. เข้าไปที่เว็บไซต์ [Meta for Developers](https://developers.facebook.com/) และล็อกอินด้วยบัญชี Facebook ของคุณ
2. ที่มุมขวาบน ให้คลิกที่เมนู **"My Apps"** (แอปของฉัน)
3. คลิกปุ่ม **"Create App"** (สร้างแอป)
4. เลือกประเภทแอปเป็น **"Other"** (อื่นๆ) -> เลือก **"Business"** (ธุรกิจ) แล้วคลิก **"Next"**
5. ตั้งชื่อแอป (App Name) เช่น `Botify MyShop` และกรอกอีเมลสำหรับติดต่อ
6. คลิก **"Create app"** (สร้างแอป) (อาจมีป๊อปอัปให้ใส่รหัสผ่าน Facebook ของคุณเพื่อยืนยัน)

---

## 2. การตั้งค่า Messenger API

1. หลังจากสร้างแอปเสร็จ จะถูกพามาที่หน้า App Dashboard 
2. ให้เลื่อนลงมาหาการ์ดที่ชื่อว่า **"Messenger"** แล้วคลิกปุ่ม **"Set Up"** (ตั้งค่า)
3. ระบบจะพาไปที่หน้าตั้งค่าของ Messenger API โดยอัตโนมัติ

---

## 3. การสร้าง Page Access Token และดู Page ID

1. ในหน้า Messenger Settings ให้เลื่อนลงมาที่หัวข้อ **"Access Tokens"** (โทเค็นการเข้าถึง)
2. คลิกปุ่ม **"Add or Remove Pages"** (เพิ่มหรือลบเพจ)
3. ป๊อปอัป Facebook จะเด้งขึ้นมา ให้คุณ **เลือกเพจ Facebook** ที่ต้องการให้บอททำงาน แล้วกดยืนยันให้สิทธิ์ทั้งหมด
4. เมื่อผูกเพจสำเร็จ ชื่อเพจของคุณจะปรากฏในตาราง
5. **หา Page ID:** คุณจะเห็นตัวเลข **Page ID** แสดงอยู่ข้าง ๆ หรือใต้ชื่อเพจของคุณ ให้คัดลอกตัวเลขนี้ไปใส่ในช่อง `Page ID` ในระบบ Botify
6. **หา Page Access Token:** คลิกปุ่ม **"Generate Token"** (สร้างโทเค็น) ที่อยู่หลังชื่อเพจ
7. ป๊อปอัปจะแสดง Token ยาว ๆ ออกมา ให้กดยืนยันแล้วคัดลอก (Copy) โทเค็นนั้นไปใส่ในช่อง `Page Access Token` ในระบบ Botify ทันที
*(ข้อควรระวัง: โทเค็นนี้จะแสดงให้เห็นเพียงครั้งเดียวเท่านั้น ห้ามทำหาย!)*

---

## 4. การตั้งค่า Webhook (สำคัญมาก!)

เพื่อให้ระบบ Botify รับข้อความจากลูกค้าและตอบกลับได้ คุณต้องตั้งค่า Webhook ในหน้าจัดการแอป:

1. กลับมาที่เมนูด้านซ้ายในหน้าแอป (App Dashboard) ของคุณ
2. ภายใต้ **Messenger** ให้คลิก **Settings** (ตั้งค่า)
3. เลื่อนลงมาที่ส่วน **Webhooks** แล้วคลิกปุ่ม **"Add Callback URL"**
4. กรอกข้อมูลดังนี้:
   - **Callback URL**: `https://<โดเมนของคุณ>/webhook-fb` (เช่น `https://botify-v4.onrender.com/webhook-fb`)
   - **Verify Token**: รหัสผ่านสำหรับยืนยัน Webhook (คุณสามารถตั้งขึ้นเอง หรือใช้ค่าเริ่มต้นจากในไฟล์ `.env` ที่ชื่อว่า `FB_VERIFY_TOKEN` ซึ่งปกติควรตั้งไว้ เช่น `my_botify_secure_token`)
5. คลิก **"Verify and Save"** (ยืนยันและบันทึก)
6. เมื่อบันทึกเสร็จ จะมีหน้าต่างของเพจที่คุณผูกไว้ปรากฏขึ้นมา ให้คลิกปุ่ม **"Add Subscriptions"** (เพิ่มการสมัครรับข้อมูล) ที่อยู่ด้านหลังชื่อเพจ
7. ติ๊กเลือกช่อง **`messages`** และ **`messaging_postbacks`** แล้วกดบันทึก

เพียงเท่านี้ Facebook ก็จะเริ่มส่งข้อความมาให้บอทของคุณแล้วครับ

---

## 5. การเปิดใช้งานแอป (App Review - ไม่บังคับ หากแชทแต่กับเพจที่เป็นแอดมิน)

สำหรับการใช้งานจริงเพื่อตอบกลับลูกค้าทั่วไป คุณจะต้องตั้งค่าแอปพลิเคชันจากโหมด **Development (การพัฒนา)** ให้เป็น **Live (ใช้งานจริง)** โดย:
1. เลื่อนไปที่เมนูด้านซ้าย เลือก **App Review** -> **Requests**
2. ร้องขอการอนุมัติสิทธิ์ `pages_messaging` 
3. และเปลี่ยนสวิตช์ด้านบน (App Mode) จาก **Development** เป็น **Live**

เพียงเท่านี้บอทของคุณก็พร้อมตอบกลับลูกค้าผ่านทาง Facebook Messenger แล้วครับ!
